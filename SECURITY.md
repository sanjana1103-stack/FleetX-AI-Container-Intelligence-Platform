# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

We take the security of FleetX seriously. If you identify a potential security vulnerability, please do not disclose it publicly via an issue tracker.

Instead, please email the repository maintainers or file a private security advisory on GitHub.

Please provide:
- Description of the vulnerability
- Step-by-step instructions to reproduce
- Potential impact and affected components

We commit to acknowledging receipt within 48 hours and providing a mitigation timeline.
