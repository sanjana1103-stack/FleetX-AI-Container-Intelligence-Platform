# Changelog

All notable changes to the **FleetX AI Container Intelligence Platform** are documented in this file.

## [2.0.0] - 2026-09-20
### Added
- **Fleet Command Center**: Real-time AI calculated Fleet Health Score (0-100 gauge) with weather, congestion, maintenance, and customs breakdown bars.
- **Live Operations Event Feed**: Scrolling ticker with live severity-categorized maritime operational events.
- **Global Logistics Timeline**: Visual milestone progression on the shipment tracker with on-time and delay statuses.
- **Advanced Disruption Digital Twin**: 8 simulation scenarios including Storm Cyclone, Port Strike, Customs Hold, Propulsion Derating, Fuel Spike, Piracy Risk (Gulf of Aden detour), Suez Canal Blockage, and Reefer Compressor Failure.
- **Dynamic Risk Engine**: Cascading simulation effects that recalculate fleet health, delay hours, vessel speed, fuel burn, CO2 efficiency, and ETA predictions.
- **Port Intelligence Upgrade**: Interactive port cards expanding with crane utilization, berth occupancy, truck queues, labor status, and weather telemetry across 104 global hubs.
- **Warehouse Digital Twin**: Animated Autonomous Guided Vehicles (AGVs) and RTG forklifts traversing storage zones with bay dwell indices and active loading/unloading queues.
- **AI Operations Copilot**: Conversational assistant capable of explaining delay root causes, comparing routing economics (Fastest vs. Eco), identifying highest-risk fleet assets, and drafting executive briefings.
- **Incident Command Center**: Comprehensive incident monitoring with Level-1 & Level-2 disruption dossiers, financial impact calculations, and exportable PDF reports.
- **Explainable AI (XAI) Modal & Command Palette**: Instant Ctrl+K global navigation and interactive feature contribution breakdown.

### Fixed
- Preserved master white/orange enterprise theme with zero layout disruptions.
- Re-routed sidebar settings button to platform configuration.
- Unified type exports to eliminate runtime module import mismatch.
- Added comprehensive offline fallbacks for all network actions.
